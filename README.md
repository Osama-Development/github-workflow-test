# GitHub Workflow Test

مشروع تجريبي عام لاختبار GitHub: ملفات وCommits وفروع وTags وReleases.

## الوظيفة
صفحة عربية متجاوبة تعرض ترحيبًا وزرًا يحدّث رسالة ويعدّ النقرات. HTML وCSS وJavaScript في ملف واحد، دون مكتبات خارجية.

## التشغيل
نزّل المستودع وافتح `index.html` في أي متصفح حديث. لا يحتاج خادمًا أو تثبيتًا.

## الفروع والإصدارات
- `main`: الإصدار الأساسي.
- `feature/improvements`: تحسين تجريبي بإضافة زر لتصفير العداد، محفوظ دون دمج.
- `v1.0.0`: الإصدار الأول من `main`.

## التحقق اليدوي
اضغط زر الترحيب وتحقق من زيادة العداد. في فرع التحسينات جرّب تصفيره.
